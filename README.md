## 📚 Topics Covered

### 🔷 1. Java Fundamentals
- Introduction to Java & JVM Architecture
- Setting up the Development Environment
- Data Types, Variables & Type Casting
- Operators & Expressions
- Input/Output in Java (`Scanner`, `BufferedReader`)
- Comments & Code Structure

---

### 🔷 2. Control Flow
- `if`, `else if`, `else` Statements
- `switch` Statements
- Loops — `for`, `while`, `do-while`
- `break`, `continue`, `return`
- Nested Loops & Pattern Programs

---

### 🔷 3. Object-Oriented Programming (OOP)
- Classes & Objects
- Constructors (Default, Parameterized, Copy)
- `this` Keyword
- **Encapsulation** — Getters & Setters
- **Inheritance** — Single, Multilevel, Hierarchical
- **Polymorphism** — Method Overloading & Overriding
- **Abstraction** — Abstract Classes & Interfaces
- `super` Keyword & Method Hiding
- `static` Members & Methods
- `final` Keyword

---

### 🔷 4. Arrays & Strings
- 1D & 2D Arrays
- Array Traversal, Sorting & Searching
- `String` Class & String Methods
- `StringBuilder` & `StringBuffer`
- String Comparison & Manipulation
- Character Arrays

---

### 🔷 5. Exception Handling
- Types of Exceptions (Checked & Unchecked)
- `try`, `catch`, `finally` blocks
- `throw` & `throws`
- Custom / User-defined Exceptions
- Multi-catch & Nested try blocks

---

### 🔷 6. Java Collections Framework
- **List** — `ArrayList`, `LinkedList`
- **Set** — `HashSet`, `LinkedHashSet`, `TreeSet`
- **Map** — `HashMap`, `LinkedHashMap`, `TreeMap`
- **Queue** — `PriorityQueue`, `Deque`
- **Stack**
- `Collections` Utility Class
- Iterators & For-each Loop

---

### 🔷 7. Multithreading & Concurrency
- Introduction to Threads
- Creating Threads (`Thread` class & `Runnable` interface)
- Thread Lifecycle
- `sleep()`, `join()`, `yield()`
- Synchronization & `synchronized` Keyword
- Inter-Thread Communication

---

### 🔷 8. File Handling
- `File` Class
- Reading & Writing Files (`FileReader`, `FileWriter`)
- `BufferedReader` & `BufferedWriter`
- `FileInputStream` & `FileOutputStream`
- Serialization & Deserialization

---

### 🔷 9. Data Structures & Algorithms in Java
- Sorting — Bubble, Selection, Insertion, Merge, Quick Sort
- Searching — Linear & Binary Search
- Recursion & Backtracking
- Linked List, Stack, Queue (Implementation)
- Binary Trees & Binary Search Trees
- Hashing

---

### 🔷 10. Advanced Java Concepts
- Generics
- Lambda Expressions
- Functional Interfaces
- Stream API
- Optional Class
- Enums
- Annotations
- `var` keyword (Java 10+)

## ⚙️ How to Run the Code

**Prerequisites:**
- Java JDK 8 or above installed
- Any IDE (IntelliJ IDEA / Eclipse / VS Code) or Terminal

**Steps:**

```bash
# 1. Clone the repository
git clone [YOUR GITHUB LINK HERE]

# 2. Navigate to any topic folder
cd Java-Programming-Course/03_OOP

# 3. Compile the Java file
javac FileName.java

# 4. Run the program
java FileName
```
